1. ВВЕДЕНИЕ
--------------------------------------------------------------------------------

Производственная (учебная) практика направлена на закрепление теоретических
знаний, полученных в ходе изучения дисциплин «Программирование»,
«Операционные системы», «Автоматизация тестирования программного обеспечения»,
а также на формирование практических навыков разработки прикладного ПО.

В рамках практики была выполнена разработка десктопного приложения
RiotScanner — программного комплекса на языке Go, предназначенного для
управления Android-эмулятором через ADB (Android Debug Bridge), анализа
изображения экрана, автоматизации пользовательского ввода и подмены
изображения виртуальной камеры эмулятора.

Проект выполняется исключительно в учебных целях: отработка навыков работы
с эмуляторами, средствами автоматизации, компьютерным зрением и
кроссплатформенной разработкой. Разработанное ПО не предназначено для обхода
систем защиты, нарушения пользовательских соглашений сторонних сервисов
и законодательства Российской Федерации. Все эксперименты проводились
в контролируемой среде с использованием тестовых аккаунтов.

2. ЦЕЛИ И ЗАДАЧИ ПРАКТИКИ
--------------------------------------------------------------------------------

2.1. Цель практики

Формирование компетенций в области автоматизации мобильных приложений,
работы с Android Debug Bridge, анализа графических данных и организации
модульной архитектуры программного обеспечения на языке Go.

2.2. Задачи практики

  1. Изучить принципы работы Android-эмулятора и утилиты ADB.
  2. Разработать модуль взаимодействия с эмулятором (запуск, остановка,
     получение скриншота, эмуляция касаний).
  3. Реализовать механизм определения состояния интерфейса по цвету пикселей.
  4. Разработать модуль эмуляции камеры (передача статического изображения
     в виртуальную камеру эмулятора).
  5. Реализовать поддержку создания и удаления клонов приложений
     в эмуляторе (через ADB и сторонние средства).
  6. Объединить модули в единый оркестратор с конфигурацией в формате YAML.
  7. Провести тестирование на платформах Windows и macOS.
  8. Оформить исходный код и разместить проект в системе контроля версий Git.

5. ОПИСАНИЕ РАЗРАБОТАННОГО ПРОГРАММНОГО КОМПЛЕКСА RIOTSCANNER
--------------------------------------------------------------------------------

5.1. Назначение

RiotScanner — консольное приложение, управляющее Android-эмулятором
и выполняющее сценарии автоматизации, заданные в конфигурационном файле.

5.2. Структура проекта

  cmd/riotscanner/          — точка входа, CLI-команды
  internal/adb/             — обёртка ADB
  internal/emulator/        — запуск и остановка AVD
  internal/automation/      — анализ пикселей, сценарии tap
  internal/camera/          — подмена изображения виртуальной камеры
  internal/clone/           — управление клонами приложений
  internal/config/          — загрузка YAML-конфигурации
  internal/orchestrator/    — главный цикл «скриншот → анализ → действие»
  configs/                  — файлы конфигурации (default.yaml, macos.yaml)

5.3. Команды приложения

  run           — запуск цикла автоматизации
  connect       — подключение к эмулятору без автоматизации
  clone-create  — создание клона приложения
  clone-delete  — удаление клона
  inject-qr     — передача QR-изображения в виртуальную камеру

5.4. Алгоритм работы оркестратора

  1. Получение скриншота экрана эмулятора (adb exec-out screencap -p).
  2. Декодирование PNG и проверка пиксельных проб (PixelProbe).
  3. При обнаружении экрана сканирования QR — инъекция изображения в камеру.
  4. При совпадении условий automation — выполнение tap по координатам.
  5. Повтор цикла с интервалом poll_ms (по умолчанию 500 мс).

5.5. Пример запуска (macOS)

  export PATH="$HOME/Library/Android/sdk/platform-tools:$PATH"
  cd riotScanner
  go build -o bin/riotscanner ./cmd/riotscanner
  ./bin/riotscanner -config configs/macos.yaml -cmd run
